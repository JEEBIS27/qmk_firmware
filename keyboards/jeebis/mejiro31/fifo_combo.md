#FIFO Comboの説明

QMKのコンボはコンボの候補キー以外のキーがコンボ判定待機中に押されるとそれを中断するような仕様になっている。

ただ、このFIFOコンボではタイムアウトになるまでコンボかどうかを待機し続ける。

##FIFO Comboの動作フロー

###定義

キューは長さ30。キーコードとタイマーを要素として保存する。
コンボのタイムアウト時間をCOMBO_TIMEOUT_MSとする。
2キーのコンボしか定義できないものとする。
A+B→Cのコンボが定義されているとしたときに、A, Bをコンボの候補キー、Cをコンボの結果キーと呼ぶことにする。

###フロー

if キューの先頭のキーのタイマーが timer >= COMBO_TIMEOUT_MSなら:
  1.先頭のキーを出力する。
  2.先頭のキー、そのキーのタイマーをキューから削除する。
else:
  1.キーを受け取ったとき、キューの最後尾にそのキーを追加。そのキーのタイマーをスタートする。
  2.キューの先頭のキーと直前に追加されたキーとのコンボが定義されていないかどうかを確かめる。
    if もしコンボ定義が見つかれば:
      1.結果キーを出力。
      2.候補キーを両方キューから削除する。
